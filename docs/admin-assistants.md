# Установка помощников администратора

Изменения подготовлены в PR. Публикация файлов в GitHub не применяет SQL и не
развёртывает Supabase Edge Functions.

## Порядок установки

1. Развернуть `supabase/functions/admin-reset-password/index.ts` под существующим
   именем `admin-reset-password`. Не отключать JWT verification.
2. Выполнить в Supabase SQL Editor целиком, по порядку:
   - `supabase/migrations/20261015_owner_and_assistant_admins.sql`;
   - `supabase/migrations/20261015_student_gameplay_for_assistants.sql`.
   Если первый файл уже применён, достаточно второго. При ошибке остановиться:
   не пропускать отдельные проверки и не запускать остаток файла вручную.
3. Опубликовать обновлённый frontend и обновить страницу игры.
4. Проверить отдельные аккаунты владельца, помощника и ученика перед выдачей
   реальных полномочий.

## Использование

Назначение: админ-панель → «Владелец» → «Администраторы» → поиск по нику →
подтверждение. У ученика должен быть класс. Отзыв прав находится в том же списке.
Назначение и отзыв сохраняют класс, статистику, валюту и инвентарь.

Помощник получает административные инструменты и остаётся обычным игроком:
обычный кулдаун, платные покупки, участие в рейтингах и обычные награды мини-игр.
Управление администраторами, административная проверка мини-игр и критические
операции остаются у владельца.

Для действий, влияющих на соревнование, предусмотрено участие владельца.
Промокод помощника создаётся выключенным и включается владельцем. Собственный
промокод помощник получить не может, в том числе после отзыва прав. Старые коды
без надёжных сведений об авторе могут потребовать нового кода от владельца.
Обычная модерация требует зарегистрированной жалобы или нарушения.

## Проверки перед выпуском

Автоматические SQL-тесты выполняются в отдельной PostgreSQL 16, без доступа к
production. Тестовая схема моделирует игровые контракты и не заменяет проверку
действующих функций Supabase.

На реальных аккаунтах проверить: назначение/отзыв, кулдаун рисования, вклад в
класс и личный рейтинг, покупки и награды, мини-игры, промокоды, обычную модерацию,
музыку и работу интерфейса на мобильном устройстве. Проверить прямой отказ в
запрещённых административных операциях под аккаунтом помощника.
