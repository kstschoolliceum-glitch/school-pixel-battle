# Java ME games — текущее состояние PR №2

В этапe 5 подключён настоящий **JS2ME** в `/javagames/`, внутри iframe `sandbox="allow-scripts"`.
Клавиатура, обучение и каталог остаются в Pixel Battle. FreeJ2ME-Web/CheerpJ не включены.

**Проверено в стенде:** реальные JAR ZIP/байткод, изображение Canvas 240×320,
19 клавиш, удержание/отпускание, пауза/продолжение, RMS reopen (1 → 2).
**15/15 целевых Node-тестов** протокола, интерфейса и host-хранилища пройдены.
Стенд использует нативный Canvas и DOM doubles: браузерные iframe/CSP/IndexedDB и звук требуют отдельной проверки.

В каталоге есть два настоящих разрешённых тестовых MIDlet и локальная конфигурация High School Hook Ups.
Коммерческого JAR в репозитории нет. На публичном домене его загрузка отключена.
**High School Hook Ups пока не подтверждена:** локальный стенд дошёл до чёрного экрана и NullPointerException в обработке графических ресурсов.
Работающий сюжет и его автосохранение не заявляются.

Маршрут: карта → «Игры» → каталог → выбор → обучение при первом входе → реальный runtime → «✕ Выход» → каталог → «Закрыть» → карта.
Выход из игры ждёт подтверждения RMS и остановки iframe; карта не перезагружается.
